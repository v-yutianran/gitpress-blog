用 GitPress 在 GitHub Pages 上搭建个人博客

背景

我想参考 GitPress.net，在自己的 GitHub 上搭一个博客，并先放三篇测试文章。

1. 了解 GitPress

GitPress.net 是一个基于 pnpm 的博客框架。文章和设置写在 Markdown 和 gitpress.json 里，由 GitHub Actions 构建成静态网站，再交给 GitHub Pages 托管。官方推荐用两个仓库：一个私有仓库放文章，一个公开仓库放构建好的网站。

2. 新建仓库并部署

电脑上的 gh 已经登录，所以直接用 gh 新建仓库，没有在网页上手动建。

一开始图省事，只用了一个公开仓库：source 分支放源码，main 分支放构建产物。后来发现每次写文章都要切分支，草稿在公开源码里也能被看到，于是改成了官方推荐的两个仓库：

  • 私有仓库 v-yutianran/gitpress-source（main 分支）：放 gitpress.json、content/posts/、content/pages/about.md、media/，主题是 classic。
  • 公开仓库 v-yutianran/v-yutianran.github.io：只放构建好的网站，由工作流自动更新。
  • 每次推送到私有仓库的 main，“GitPress Build” 工作流就用 tap6/build-action@v1 构建，再通过部署密钥（公开仓库上一把可写的 SSH deploy key，私钥存成私有仓库的 GITPRESS_DEPLOY_KEY secret）推送到公开仓库的 main。
  • GitHub Pages 从公开仓库 main 分支的根目录提供网站。

三篇测试文章：

  1. 欢迎来到我的博客
  2. Markdown 写作测试（标题、列表、代码块、表格、引用）
  3. 第三篇测试文章

3. 换成根域名

网站一开始在 https://v-yutianran.github.io/gitpress-blog/。为了直接用 https://v-yutianran.github.io，做了这几件事：

  • 把仓库改名为 v-yutianran.github.io
  • 把 gitpress.json 里的站点地址改成 https://v-yutianran.github.io，基础路径改成 /
  • 重新构建并部署，用 curl 确认首页和三篇文章都返回 200

4. 一键发布的 skill

最后写了一个 gitpress-publish skill。以后只要给它一篇 md，它会：

  1. 补全 frontmatter（标题、日期、标签、摘要）
  2. 用英文 slug 保存到 content/posts/
  3. 推送到私有仓库 gitpress-source 的 main 分支，并等待构建和部署完成
  4. 检查文章能正常打开，再返回线上链接
  5. 部署完成后用 tg-notify 给我发一条 Telegram 通知，附上标题和链接

注意事项

  • 文章和草稿都在私有仓库里，draft: true 的草稿不会出现在网站上，也不会公开。
  • 公开仓库的 main 每次构建都会被整个覆盖，改内容请改私有仓库。
